## Fonts

The project self-hosts the Latin WOFF2 subsets served by the Google Fonts API on 2026-09-04. Both font families are published under the SIL Open Font License.

| Local file                                        | Family                    | Source                                                                   |
| ------------------------------------------------- | ------------------------- | ------------------------------------------------------------------------ |
| `src/assets/fonts/manrope-latin-variable.woff2`   | Manrope variable, 400–800 | [Google Fonts: Manrope](https://fonts.google.com/specimen/Manrope)       |
| `src/assets/fonts/newsreader-latin-regular.woff2` | Newsreader roman, 400     | [Google Fonts: Newsreader](https://fonts.google.com/specimen/Newsreader) |
| `src/assets/fonts/newsreader-latin-italic.woff2`  | Newsreader italic, 400    | [Google Fonts: Newsreader](https://fonts.google.com/specimen/Newsreader) |

Static Newsreader faces are used instead of the much larger variable files. This preserves the editorial roman/italic contrast while reducing the initial local font payload by roughly 226 KB.
