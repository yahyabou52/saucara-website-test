# Risks

| ID    | Risk                                                                                         | Level  | Mitigation                                                                                                                  | Residual / verification                                          |
| ----- | -------------------------------------------------------------------------------------------- | ------ | --------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| R-001 | Stock photos could be mistaken for real SAUCARA work.                                        | medium | Use local licensed files, descriptive alt text, asset documentation, and visible demo-photography disclosure.               | Independent truth/copy review.                                   |
| R-002 | A numberless WhatsApp link proves message preparation but does not reach a business account. | medium | Centralize recipient configuration, label demo behavior, keep message useful, and document production requirement.          | Inspect hrefs; owner supplies number before launch.              |
| R-003 | Long one-page content can bury conversion on mobile.                                         | medium | Compact copy, contextual CTAs, strong anchors, no obstructive floating bar.                                                 | Mobile screenshots and journey timing.                           |
| R-004 | Gold-on-cream or fine serif typography can fail contrast/readability.                        | high   | Use gold only on deep green or decorative rules; use darker gold ink on cream; maintain 16px+ body and test contrast/zoom.  | Automated axe plus manual contrast/200% review.                  |
| R-005 | Image/font weight can degrade LCP and layout stability.                                      | medium | Local WOFF2, responsive Next Image, intrinsic dimensions, preload only hero, lazy-load below fold, compress assets.         | Build output, Lighthouse/browser measurements, image load tests. |
| R-006 | Form success language could imply a sent/confirmed order.                                    | high   | Define success as “message prepared,” expose a separate outbound link, and test forbidden wording.                          | Unit/component/E2E and copy audit.                               |
| R-007 | Demo policies could be read as real commercial/legal terms.                                  | medium | Label hours, testimonials, policies, and contact details fictional; set `noindex`; avoid guarantees and exact legal claims. | Independent content review; replace before launch.               |
| R-008 | External WhatsApp/Pexels/font availability could make build/runtime unstable.                | low    | Download assets/fonts locally; no runtime third-party requests except user-initiated WhatsApp navigation.                   | Network/request audit and offline image/font load check.         |
